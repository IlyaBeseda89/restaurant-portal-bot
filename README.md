# Портал ресторанов в Telegram

Бот для сотрудников: база знаний, обратная связь, тренинги, онбординг новичков.
Сделан по ТЗ v1.0 (октябрь 2026). Готовы **Этап 1 (MVP)**, карточки продуктов с разделением по концепциям и тренинги (расписание, заявки, напоминания, календарь).

## Что уже работает

- **Регистрация по персональной ссылке** `t.me/<бот>?start=<роль>_<код>`.
  Бот спрашивает ФИО и телефон и сверяет их с листом «Сотрудники».
  Если человека нет в списке, ссылкой уже кто-то воспользовался или ФИО не совпадает, заявка уходит в чат HR.
- **Роли и меню.** Меню собирается по роли из таблицы. Если HR поменяет роль в таблице, меню обновится само.
  Если поставить «активен = нет», доступ закрывается.
- **Флаг «новичок».** Ставится автоматически на 28 дней от даты старта. В колонке «новичок» HR может вручную поставить «да» или «нет».
- **📚 База знаний.** Сначала категории, внутри материалы. Сотрудник видит материалы своей концепции и общие («все»).
  Каждое открытие материала пишется в журнал активности.
- **💬 Обратная связь.** Категория, текст (можно с фото или файлом), затем выбор: анонимно или с контактом.
  Карточка с метками `#категория #ресторан` уходит в служебный чат, там же кнопками меняется статус.
  **Анонимные обращения** не оставляют следов: в них нет telegram_id, ФИО и записи в журнале.
  Ресторан подставляется из профиля всегда, поэтому у каждого отзыва есть точка. Видят её только участники служебного
  чата (ТУ и собственник) и таблица. У кого ресторана в профиле нет (офис, HR), выбирают его кнопками, пропустить этот шаг нельзя.
- **🍽 Карточки продуктов.** Категория меню → блюдо → карточка с фото, составом, аллергенами, методом, сочетаниями и «что рассказать гостю».
  Показываются карточки своей концепции и общие. Блюдо правится одной строкой в таблице «Карточки продуктов», новое блюдо — новая строка.
  Фото берутся по ссылке в колонке `фото_url` (ссылка на файл в Google Диске с доступом «всем, у кого есть ссылка» подойдёт).
  Новичку доступна кнопка «Отметить изученным» (пишется в лист «Прогресс»).
- **❓ Помощь.** Текст берётся с листа «Тексты» (ключ `помощь`).
- Разделы следующих этапов (тренинги, заявки, админка, «Мой старт») уже видны в меню и пока отвечают «появится на этапе N».

## Разделение по концепциям

У каждой концепции своё поле для изучения: сотрудник видит карточки продуктов и материалы **только своей концепции** плюс **общие**.

- Концепция сотрудника определяется по его ресторану (лист «Рестораны», колонка `концепция_id`). У модератора концепции по листу «Концепции» (колонка `модератор_id`).
- В колонке `концепция_id` листов «Материалы» и «Карточки продуктов» пишется id концепции или слово **все** для общих материалов (пищевая безопасность и т. п.).
  Пустая ячейка тоже считается «все», поэтому для закрытых материалов обязательно указывайте концепцию.
- Если у сотрудника не указан ресторан, или у ресторана не указана концепция, он видит **только общие** материалы. Чужие ему не показываются никогда.
- ТУ, менеджер по обучению и HR работают со всеми концепциями. Любому другому человеку (например, PR-директору) это можно
  открыть, поставив «да» в колонке `все_концепции` листа «Сотрудники». «Нет» в этой колонке, наоборот, ограничивает его своей концепцией.
  Перед «Базой знаний» и «Карточками продуктов» им предлагается выбрать концепцию, а кнопка «🔀 Другая концепция» позволяет переключиться.

## Как устроен код

```
app/
  __main__.py          запуск бота
  config.py            настройки из .env
  schema.py            листы и колонки (ТЗ, раздел 4)
  roles.py             роли и матрица доступа (ТЗ, 2.2)
  models.py            сотрудник, материал, обращение…
  keyboards.py         кнопки и главное меню
  middlewares.py       «кто пишет»: поиск сотрудника по telegram_id
  handlers/            диалоги: регистрация, база знаний, обратная связь, меню
  storage/
    repository.py      ЕДИНЫЙ СЛОЙ ХРАНЕНИЯ — диалоги работают только через него
    sqlite_backend.py  локальная база (проверка, тесты)
    sheets_backend.py  Google Sheets (боевой режим)
  cli.py               служебные команды
tests/                 автотесты
```

При переходе на облачную БД добавится ещё один файл в `storage/`. Диалоги менять не придётся.

## Запуск на своём компьютере (проверка без Google)

Нужен Python 3.12 или новее.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt

cp .env.example .env               # впишите BOT_TOKEN
python -m app.cli demo             # демо-данные: рестораны, материалы, 7 сотрудников
python -m app.cli links            # персональные ссылки для всех
python -m app                      # запуск бота
```

Чтобы войти как HR, откройте ссылку для «Тестов Тест Тестович» и введите это ФИО.
Остальные демо-сотрудники нужны, чтобы посмотреть меню других ролей.

Автотесты: `pytest`

## Переход на Google Sheets

1. В Google Cloud Console создайте проект, включите **Google Sheets API** и **Google Drive API**.
2. Создайте **сервисный аккаунт** и скачайте ключ JSON. Положите его в `secrets/google.json`.
3. Создайте пустую таблицу Google и дайте доступ «Редактор» на email сервисного аккаунта (он есть в JSON, поле `client_email`).
4. В `.env`: `STORAGE=sheets`, `SPREADSHEET_ID=<id из ссылки на таблицу>`.
5. `python -m app.cli init` создаст все листы с нужными колонками.
   Чтобы сначала посмотреть на примере, выполните `python -m app.cli demo`.

Колонки можно переставлять и добавлять свои: бот ищет колонки по названию в первой строке.
Изменения в таблице бот видит в пределах минуты (`CACHE_TTL_SECONDS`).

**Как заполнять «Сотрудники»:** `id` — любой уникальный номер; `роль` — сотрудник / директор / ТУ /
менеджер по обучению / модератор / HR; `дата_старта` — ДД.ММ.ГГГГ; `пригласительный_код` можно оставить
пустым, тогда `python -m app.cli links` придумает коды сам и покажет ссылки. `telegram_id` бот заполнит сам.

## Тренинги и заявки

- **🎓 Тренинги** (все): ближайшие 5 тренингов, расписание по месяцам, кнопка «В мой календарь» (файл .ics; это скачиваемый файл, живой подписки нет, при изменениях скачайте заново; длительность в календаре 2 часа).
- **📋 Заявка на тренинг** (директор, ТУ, менеджер): тема, формат, площадка, желаемые даты, участники (по одному в строке «Фамилия Имя — должность»).
- **🗂 Заявки** (менеджер по обучению): принять (назначить дату, ведущего, тренинг попадёт в расписание), перенести или отклонить с комментарием. Заявитель и найденные в боте участники получают уведомление.
- **🗓 Расписание** (менеджер): отметить проведённым или отменить с уведомлением. Дату, площадку, ведущего правьте в листе «Расписание».
- Напоминание за сутки до начала уходит автоматически (проверка раз в 10 минут), в таблице ставится «да» в колонке «напоминание».
- Даты в таблице пишутся как `ДД.ММ.ГГГГ ЧЧ:ММ`, время местное (часовой пояс из настроек).

## Админка в боте (этап 2.3)

Кнопка «⚙️ Админка» есть у менеджера по обучению, модератора и HR.

- Сотрудники: добавить (ФИО, роль, ресторан, должность) и сразу получить пригласительную ссылку; найти по части имени; сменить роль и ресторан; отключить и включить.
- Материалы и карточки блюд: добавить и скрыть. Ссылки на файлы Google Диска бот определяет сам и отправляет файлом в чат.
- HR назначает любые роли, менеджер по обучению любые, кроме HR, модератор только сотрудника и директора своей концепции и работает с материалами только своей концепции.
- Свою роль менять и себя отключать нельзя. Скрытое остаётся в таблице с «активен = нет», вернуть можно там.
- Все действия пишутся в «Журнал активности».

## Мой старт и статистика (этап 3)

- «🌱 Мой старт»: чек-лист новичка собирается из материалов с «для_новичков = да» для его концепции (и общих). Сотрудник открывает материал, нажимает «✅ Изучил(а)», видит прогресс. Когда весь чек-лист пройден, менеджеры по обучению получают уведомление. Отметки хранятся на листе «Прогресс».
- Приветствие в «Мой старт» можно задать для каждой концепции: лист «Тексты», ключ «старт_приветствие_<id концепции>». Общий текст: ключ «старт_приветствие».
- «📊 Статистика» (ТУ, менеджер по обучению, модератор, HR): сотрудники и вошедшие в бота, активность за 7 дней и самые открываемые материалы, заявки на тренинги по статусам, обратная связь за 30 дней, прогресс новичков. Модератор видит только свою концепцию.

## Группы сотрудников

Три группы: «руководители» (директора, ТУ, шефы, су-шефы, шеф-бармены), «менеджмент» (менеджеры, старшие бармены) и «сотрудники» (все остальные). Старшие видят всё, что предназначено нижним: материал «для менеджмента» видят менеджмент и руководители, материал без группы видят все.

- У сотрудника группа лежит в колонке «группа» листа «Сотрудники» (или задаётся в админке, кнопка «👥 Группа»). Если колонка пуста, группа определяется по роли и должности («шеф», «менеджер», «старший бармен» и т. п.).
- У материала группа в колонке «для_групп» листа «Материалы» (пусто = всем; допустимо «менеджмент» или «руководители»). Непонятное значение закрывает материал для всех, кроме руководителей.
- Группа работает вместе с концепцией: сотрудник видит материалы только своей концепции и только своей группы и ниже.

## Расписание тренингов: правка, запись, очередь

- В «🗓 Расписание» у менеджера по обучению у каждого тренинга кнопки: «✏️ Изменить» (дата и время, площадка, ведущий, число мест, концепция), «👥 Записанные», «🔓 Открыть запись». При изменении даты, площадки или ведущего записанным и участникам заявки уходит уведомление, напоминание за сутки уходит заново.
- Когда запись открыта, в «🎓 Тренинги» у сотрудников появляется «✍️ Записаться». Если мест нет (число мест задано), человек встаёт в очередь, а при отмене чьей-то записи или увеличении мест первый из очереди записывается сам и получает сообщение.
- Тренинг можно привязать к концепции: сотрудники других концепций его не увидят. ТУ, менеджер по обучению и HR видят все.
- Записи лежат на листе «Записи на тренинги» (статусы: записан, очередь, отменил, был, не был). Новые колонки «запись» и «концепция_id» в «Расписании» бот добавит сам.

## Присутствие и оценки тренингов

- После «✅ Проведён» у менеджера по обучению появляется «📋 Присутствие и оценки»: список участников (названные в заявке и записавшиеся сами). Нажатие на имя переключает ⬜ не отмечен, ✅ был, ❌ не был.
- «📨 Запросить оценки» отправляет тем, кто был, сообщение с кнопками 1–5. Оценить может только отмеченный как «был», по одному разу на тренинг. Средняя оценка видна в списке присутствия.
- В «📊 Статистике» появилась строка: проведено тренингов, посещений и средняя оценка. Данные лежат на листе «Записи на тренинги».
## Журнал активности

Журнал не лежит в Google-таблице и не хранит имён. Бот считает действия за день (например, сколько раз открыли материал) в разрезе концепции и записывает итоги в локальный файл `data/activity.sqlite3` (при `STORAGE=sheets`). Для каждого дня хранится ещё число разных активных сотрудников, но не кто именно. Записи старше 60 дней (`ACTIVITY_DAYS`) удаляются автоматически. Старый лист «Журнал активности» в таблице бот больше не заполняет, его можно удалить.

## Добавление тренинга из бота

Менеджер по обучению и HR (администратор) открывают «🗓 Расписание» → «➕ Добавить тренинг». Шаги: тема (выбрать из списка или создать новую), формат (онлайн, офлайн или гибрид), дата и время, площадка (для онлайн не нужна), ведущий, концепция (все или одна), число мест (0 без ограничения) и открыть ли запись сразу. Тренинг сразу появляется в листе «Расписание».

## Инструкция по боту в «Мой старт»

В «🌱 Мой старт» есть кнопка «📖 Как пользоваться ботом»: бот присылает 7 слайдов-картинок (меню, «Мой старт», база знаний и карточки, тренинги, обратная связь, помощь). Слайды лежат в `app/assets/guide/`; чтобы поменять тексты, правьте `tools/make_guide.py` и запустите `python tools/make_guide.py` (нужен Pillow, самому боту он не нужен).

## Новости
Кнопка «📰 Новости» есть у всех. Лента показывает общие новости и новости своей концепции (ТУ, менеджер по обучению и HR видят все). Писать могут директор, ТУ, менеджер по обучению, модератор, HR и все из группы «руководители». Порядок: заголовок, текст, фото (по желанию), аудитория, предпросмотр, затем «Опубликовать и разослать» (уведомление в личку) или «Только в ленту». Те, кто работает со всеми концепциями, выбирают «для всех» или одну концепцию, остальные пишут для своей. Скрыть новость может автор, ТУ, менеджер по обучению или HR. Данные хранятся на листе «Новости» (создаётся при запуске).

## Карточки продуктов внутри базы знаний
Отдельной кнопки «Карточки продуктов» в меню больше нет: в «📚 База знаний» последним пунктом идёт «🍽 Карточки продуктов» (в разделе есть кнопка «⬅️ В базу знаний»). Старая кнопка у тех, у кого меню ещё не обновилось, продолжает работать.

## Концепция сотрудника определяется автоматически
Концепция берётся из ресторана сотрудника (у модератора из листа «Концепции»), отдельно выбирать её не нужно. Она показана в карточке сотрудника и в сообщении после добавления. Линейный сотрудник видит материалы и карточки только своей концепции и общие. Модератору при добавлении материала или карточки концепцию тоже не нужно выбирать.
